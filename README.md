# Fertilizer Helper (温室营养液决策助手)

Nutrient solution calculator for protected horticulture, derived from
*Nutrient Solutions for Greenhouse Crops* (WUR / Eurofins / Nouryon / SQM / Yara,
2020, version 4, ISBN 9789464021844).

设施园艺营养液精算系统，依据 WUR《温室作物营养液》2020 年第 4 版编制。

> The YAML block at the top of this file configures Hugging Face Spaces.
> It is ignored by GitHub and by Render — leave it in place.

## What it does

Eight calculation modules behind a bilingual (English / 中文) web interface:

| Module | Purpose |
|---|---|
| M1 | Base water classification, ppm → mmol/L, HCO₃ acid dosing with pH buffer |
| M2 | Crop sodium ceiling and forced-discharge volume |
| M3 | Leaching fraction and ΔEC wash trigger |
| M4 | Three-level root-zone feedback correction |
| M5 | Crop stage steering and dry-back targets |
| M6 | A/B stock tank separation and Fe-chelate selection |
| M7 | Recipe pipeline and base-water nutrient deduction |
| M8 | Emergency gate and root-zone diagnostics |

All numeric output is computed deterministically. Nothing is generated by a
language model.

## Architecture

```
constants.py   reference data — atomic weights, fertilisers, crop benchmarks
engine.py      pure calculation layer, no I/O
main.py        FastAPI routes + the test suite; also serves index.html
index.html     single-file bilingual frontend
design.md      technical design document
```

## Run locally

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

Then open <http://127.0.0.1:8000>.

Run the tests:

```bash
python main.py test
```

## Optional: vendor Tailwind

The frontend loads Tailwind from `vendor/tailwind.js` and falls back to
`cdn.tailwindcss.com` if that file is absent. Vendoring removes the external
dependency, which matters on networks where the CDN is slow or unreachable:

```bash
mkdir -p vendor && curl -L https://cdn.tailwindcss.com -o vendor/tailwind.js
```

## Deployment

`render.yaml` (Render), `Procfile` (Heroku-style), and `Dockerfile`
(Hugging Face Spaces / Zeabur / Fly.io) are all included. The app serves its own
frontend, so a single web service is all that is needed.

Environment variables:

| Variable | Default | Meaning |
|---|---|---|
| `PORT` | `8000` | Port to bind. Injected by most platforms. |
| `HOST` | `127.0.0.1` | Bind address. Use `0.0.0.0` in containers. |
| `ALLOWED_ORIGINS` | `*` | Comma-separated CORS allowlist. |
